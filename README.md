# Codex Quota Monitor

Codex Quota Monitor 是一个codex插件，帮你查看账户还剩多少额度、各个任务大约用了多少，以及按当前节奏还能运行多久。**监控本身不消耗 Codex 额度**；实际任务和用于打开、询问插件的对话仍正常消耗额度。

账户余额来自官方返回，任务消耗和续航时间属于估算。

[English README](./README.en.md) · [故障排查](./docs/diagnosis.md)

## 快速开始

需要支持本地插件的 Codex / ChatGPT 桌面端、Node.js 22.13 或更新版本，以及兼容的 Codex CLI。

把下面这句话发给 Codex，让它安装并打开插件：

```text
请安装并启动这个插件，完成后在聊天中给出可点击的网址：https://github.com/tristan-me/codex-quota-monitor
```

![安装插件并打开面板](docs/media/install-and-launch.gif)

安装后，在新的本地任务中输入 `@`，选择 **Codex Quota Monitor**，发送：`打开 Codex 额度监控器。`，再点击返回的面板链接。首次打开时，可能需要稍等片刻加载账户与任务数据。

![选择插件并打开额度监控器](docs/media/open-plugin.gif)

## 你可以看到什么

| 内容 | 能帮你判断什么 |
| --- | --- |
| 账户额度 | 当前已用、剩余、最近更新时间和重置倒计时 |
| 任务与最近一轮 | 总耗时、估算额度、平均每 1% 能用多久，以及最近一轮的预测 |
| 子任务 | 展开查看子任务，了解父子任务各自的额度贡献 |
| 消耗归因 | 了解已观察到的账户消耗中，有多少能与本机任务对应，以及尚未归因的部分 |
| 余量趋势 | 保留窗口内跨重置的有效样本，标明统计起点与最新余量；图例区分已记录与未记录或损坏区间，后者用暗线连接两端已知样本 |
| 模型与推理档位 | 比较本机观察到的速度，并查看有来源标注的外部参考 |
| 重置与续航 | 个人重置倒计时、预计额度用尽时间、最近两次官方全局重置公告，以及第三方预测 |

## 怎样理解任务数据

- **任务总计**：所选统计窗口内的所有轮次，以及已发现子任务的消耗。页面标明“近 X 小时任务耗时”；持续运行填满窗口后，新增时间与移出窗口的旧时间相抵，数值可能保持不变。
- **最近一次会话**：最近一轮，以及这一轮启动的子任务。复用已有子任务时，只计入属于这一轮的执行。
- 父子任务的额度相加，**并行耗时只算一次**。页面会显示额度拆分和本轮包含的子任务数量。
- **正在运行的任务优先显示**；运行中的任务按最近一轮启动时间从新到旧排序，待机任务按最后结束时间从新到旧排序。某个任务结束后，会移到仍在运行的任务后面。
- 运行中的预测优先参考最近 5 秒的消耗节奏；样本不足时，若本轮已有平均值则用它预测，否则显示 `—`。已完成任务保留可用的该轮预测。

小额消耗会自动显示更多小数位，避免把很小的正数看成零。部分已完成的短任务，在记录足够时可以补估额度，并明确标注；补估结果可跨重启和后续轮次保留；有更完整的本轮用量记录时会自动更新，超出统计窗口后清理。

任务估算受模型差异、其他设备的使用和记录完整程度影响，不能当作官方逐任务账单。`—` 表示缺少可靠样本；预测时间也不是未来用量的保证。

“监控期间归因”遇到不完整旧记录时，会从后续可用记录起算并标明时间，保留其他可用的任务历史。归因面板按已经读到的账户变化计算，补估值仅作为任务参考。尚未观察到额度变化时，会显示等待状态。

## 设置与日常使用

- **统计窗口**默认最近 24 小时，可改为 1–168 小时。调整只影响插件统计，不删除 Codex 对话；已清理的用量样本不能靠扩大窗口找回。
- **刷新频率**默认每 5 秒更新面板、每 30 秒读取账户额度，可在设置中调整，也可暂停后台读取并查看已有记录。
- **查找任务**支持标题关键词和完整 ID，多项查询可用空格或逗号分隔。默认每页 5 个，可翻页、展开更多任务或展开子任务；自动刷新会保留筛选和展开状态。
- **快速导航**可用右侧目录跳到会话、账户、趋势、模型、重置和设置。
- **默认模型偏好**可选择节省额度、平衡或优先质量。自动切换需要主动开启，只影响后续新任务；可以关闭并恢复原先的默认设置；如果你已在别处改过默认值，恢复时会提示冲突。
- 打开面板时的估算说明可勾选“不再提醒”，也能在设置中恢复提醒。

模型参考费用不等于你的订阅额度消耗。个人重置倒计时与第三方预测会分别标注来源；第三方概率、参考时段以及全局公告，都不保证你的账户会在某个时刻收到重置。

## 关闭后怎样找回

可以将面板返回的**完整地址**保存为书签。关闭网页不会停止后台服务，服务仍在同一台电脑运行时，可以直接从书签回来。

电脑重启或服务停止后，书签不会自动启动插件。重新在本地任务中打开插件，或运行 `Open-Monitor.command`，再使用返回的地址。面板是独立的本机页面，地址不适用于其他设备，也不要公开分享。

![将完整面板地址加入书签](docs/images/bookmark.jpg)


</details>

## 隐私

插件只提取统计所需的任务名称、模型、时间、状态和用量信息，不保存或上传你的提问与回答正文，也不读取认证文件。任务统计保存在本机；读取公开模型和重置参考时，不会发送本机任务数据。

分享截图或提交问题前，请去掉本机面板地址、账户额度、私人任务名称和 ID、工作目录及对话内容。
